# External release gates (source preparation is not operational evidence)

1. **Cloudflare:** provision sellerhisab-billing / sellerhisab-connectors and their DLQs; verify producer/consumer bindings, concurrency and alerts. Configure Workers Logs retention and owned notification channel. Automatic traces are disabled because OAuth/token query URLs need a redaction review. Test a synthetic error against staging, verify request ID + actual Version Metadata ID, and observe a real alert. Use current account limits for the D1/R2 thresholds in slo-policy.json.
2. **Billing:** resolve any pending_review payment intent by exact provider receipt, amount/currency and owner. Attach an existing verified order in a reviewed operation; never blindly repeat order creation. Configure and test Razorpay webhook events/secrets/retries and sandbox capture/refund/dispute flows. Confirm MSG91 allowed domains, OTP replay behavior and admin recovery restrictions.
3. **Connectors:** confirm Amazon app roles/quotas; Shopify read_all_orders/history and Payments scopes plus quarterly API-version review; Flipkart app approval, notification signing contract and any VAPT prerequisite; WooCommerce merchant read-only authorization. Provider notification delivery and approvals require provider-side evidence. No marketplace writes/repricing are enabled.
4. **SEO measurement:** verified Search Console owner submits the existing sitemap and inspects current same-page bilingual URLs, canonicals and indexing. Language-specific URL activation is an optional future editorial decision, not a launch prerequisite; if explicitly activated, verify complete translations and reciprocal hi/en canonicals/hreflang first. Review Search/Discover and any available generative-AI reports monthly. Record report availability and actual metrics; no invented AI visibility/ranking claims. Save baseline clicks/impressions/indexed URLs/CWV before a rollout. llms.txt is informational.
5. **Privacy/legal:** qualified counsel verifies DPDP/CERT-In applicability, commencement, notification duties, retention/log location, lawful purposes and processor roles. Complete owners/DPA/vendor review in data-governance.json; do not set invented statutory durations.
6. **DR/security:** execute a non-production Time Travel restore and incident tabletop with signed evidence. VAPT scope: seller/admin auth and OTP recovery, session/step-up, tenant IDOR/RBAC, billing signature/capture/idempotency, Queue replay/leases, connector OAuth/SSRF/token rotation, import XSS/limits, R2 media, SEO governance and export/deletion. Include negative tests and retest evidence; no pentest completion is claimed.

Production migration APPLY and deploy remain separate explicit owner approval gates. No production action was performed by this implementation task.
