# SellerHisab F5 — CA Close + Claim Evidence + Unified Action Inbox

F5 stays website-first. It does not create another ERP dashboard and it does not change login/admin behavior.

## Seller-facing outcomes

- A monthly close readiness state: Ready / Review / Blocked.
- A deterministic checklist for required costs, order↔settlement linkage, payout↔bank matching, return finality and source lineage.
- Claim candidates only for deterministic short, missing or failed payout evidence.
- Ambiguous/incomplete payout evidence remains review-only and is never labelled recoverable.
- A CA close workbook with channel close, normalized order ledger, payout claims, source evidence, action inbox, exceptions and methodology.
- A claim-evidence ZIP containing normalized reconciliation facts and source references; raw marketplace/customer files are not copied into the ZIP.
- One unified action inbox combining payout recovery, open returns/RTO, product economics and close blockers.
- Ranking uses money impact, confidence, urgency and effort, with explicit close-blocker overrides.

## Accounting boundary

SellerHisab prepares commerce reconciliation evidence. It does not file GST, determine tax applicability, replace a ledger/accounting system or replace accountant/professional review.

## Data / migration

No D1 migration. F5 is derived from the existing local analysis result and existing normalized source lineage.
